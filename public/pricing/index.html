ExtractMint is currently a local-first static web app for fast conversions and accountant review workflows. This page outlines the roadmap to a paid, firm-grade SaaS.

Current status

No sign-up. No payments. Browser-side processing with optional local caches you control.

Roadmap focus: batch workflows, auditability, and API access.

What you get today (free)

  • PDF and scanned statement conversion with OCR fallback (in-browser).
  • Balance trail checks and reconciliation sheet exports.
  • Review JSON + review-pack ZIP handoff for accountant workflows.
  • Optional local caches (OCR + PDF review index) you can clear in-app.

Starter (planned)

For founders and operators who convert a few documents per week.

  • Credits or usage-based billing.
  • Saved projects and history.
  • Priority statement-format improvements.

Pro (planned)

For bookkeepers and solo accountants who do recurring client work.

  • Batch review packs and templates.
  • Export rules (categories, memos, mapping).
  • Basic audit logs and validation reports.

Firm (planned)

For firms that need standardized workflows and shared controls.

  • Team workspaces + permissions.
  • API access and webhooks.
  • Support for custom bank formats.

Why this exists

  • Many tools require uploading statements to a server. ExtractMint prioritizes local-first workflows.
  • Accountants need reviewability: balance checks, reconciliations, and handoffs — not just “export a table”.
  • We aim to earn trust with clear privacy controls and verifiable validation signals.
