# ExtractMint Pricing

ExtractMint is currently a **free local-first static web app**. There is no sign-up and no payment flow yet.

This page outlines the roadmap from today’s prototype to a paid, accountant-grade SaaS.

## What you get today (free)

- PDF and scanned statement conversion with OCR fallback (in-browser).
- Balance trail checks and reconciliation sheet exports.
- Review JSON + review-pack ZIP handoff for accountant workflows.
- Optional local caches (OCR + PDF review index) that can be cleared in-app.

## Planned tiers (not live yet)

### Starter (planned)

For founders and operators converting a few documents per week.

- credits / usage-based billing
- saved history and projects
- priority format improvements

### Pro (planned)

For solo accountants and bookkeepers processing recurring client statements.

- batch review packs and templates
- export rules (categories, mapping)
- basic audit logs and validation reports

### Firm (planned)

For accounting firms that need shared controls.

- team workspaces and permissions
- API access and webhooks
- custom bank format support
