# PDF Bank Statement to Excel

> ExtractMint turns text-based PDF statement tables into clean Excel columns for review and reconciliation.

## Use Case

Upload a text-based PDF bank statement when you need a spreadsheet-ready file for accounting import, client reporting, monthly reconciliation, or internal finance review.

## Fields Extracted

- Transaction date
- Description
- Reference
- Amount
- Withdrawal
- Deposit
- Balance
- Confidence and source signals

## Review Guidance

Text-based PDFs are usually the strongest input. After conversion, compare opening and closing balances, review flagged rows, and spot-check large transactions before using the workbook.

## Outputs

ExtractMint can export PDF statement data as XLSX, CSV, DOCX, PDF, QBO, review JSON, review-pack ZIP, or a combined workbook.
