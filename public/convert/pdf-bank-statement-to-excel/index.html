Is your PDF text-based?

Open the statement and try to select or copy a transaction description. If you can select the text, the PDF usually contains embedded text and is a good fit for this workflow. A PDF made from page images is a scan; see the scanned statement guide.

ExtractMint first reads text from PDF pages. When it finds very little embedded text, it may try browser OCR automatically. OCR depends on scan quality, so a scanned file still needs careful review.

Review the statement before relying on a conversion

  1. Confirm the account and statement period, then compare the first and last transaction dates with the PDF.
  2. Check descriptions and references, including rows that wrap across lines or continue on another page.
  3. Verify each amount's sign and whether it is a debit or credit. Date order can also be ambiguous across regional formats.
  4. Compare opening and closing balances and spot-check running balance changes against the transactions.
  5. Resolve review flags and reconcile totals with the source before importing or sharing the exported file.

A matching balance trail is a useful consistency check; it does not prove that every transaction was extracted correctly.

Review and batch files

Review JSON saves extracted row details. A review-pack ZIP can include source PDFs if you enable that option; multiple converted files can also be combined into one workbook.

Bank formats and accuracy

ExtractMint uses general text and row extraction; no bank-specific format has been independently validated against real statements. Column order, date notation, wrapped descriptions, currencies, and PDF text encoding vary. An unfamiliar layout may produce incomplete or incorrect fields.

Confidence and balance checks are review signals, not a guarantee of accuracy. Verify every material field against the original statement before using the output for bookkeeping, reporting, or an accounting import.

What is the difference between a text PDF and a scanned PDF?

A text PDF contains selectable text that the browser can read directly. A scan is typically an image of each page and needs OCR. Some PDFs combine both; ExtractMint may try OCR if little embedded text is found. See the scanned PDF guide.

Does a valid balance check mean every row is correct?

No. It means the balance transitions that could be checked are consistent with the extracted values. Missing transactions, incorrect descriptions, or matching misread values may not be caught, so compare the export with the source.

Which formats can I export?

Excel XLSX, CSV, DOCX, PDF, and QBO are available, along with review JSON and a review-pack ZIP. Combined XLSX is available when you have converted multiple files.
