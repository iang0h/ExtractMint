Automatic OCR for PDFs

ExtractMint first checks a PDF for selectable text. If it finds little text, it renders and OCRs the pages in your browser. For a text PDF that needs re-reading, turn on “Force OCR (scanned PDFs)” in the converter to OCR every page. Images use OCR directly.

Choose the document language

The converter offers English, Malay, Indonesian, and Chinese (Simplified). Choose the language used in the statement before processing; mixed-language text or unfamiliar terms may still need correction.

Start with a clean scan

Use a sharp, high-resolution scan with the page straight, evenly lit, and fully in frame. Avoid blur, glare, shadows, compression artifacts, and handwriting over transaction rows.

Check the details OCR can confuse

Compare dates and descriptions with the source. Check decimal separators, minus signs, parentheses, and whether each transaction is a debit or credit. A small character error can change an amount or its direction.

Reconcile balances and page breaks

Look for transactions split or skipped at page boundaries. Compare opening and closing balances, deposits, withdrawals, and running balances. A balance check can flag a discrepancy, but it does not prove every OCR result is correct.

Review, edit, then export

Inspect the extracted rows in the converter and correct fields before downloading. Exports include XLSX, CSV, DOCX, PDF, QBO, review JSON, review-pack ZIP, and a combined workbook.

Processing and bank-format limits

In this static build, core file reading, PDF OCR, image OCR, and row extraction run in your browser. Optional “Persist OCR cache” and “Persist PDF review index” settings store derived text in this browser for repeat work; you can clear those caches in the converter. If you use the optional assistant, your question, file name, document details, and up to five extracted rows are sent to its endpoint; a configured AI provider may receive that context. The original PDF is not sent by that assistant request. See the privacy details.

Bank statement layouts differ, and no bank-specific format has been independently validated against real statements. OCR language support is not a claim of bank coverage or guaranteed accuracy. Review each export against its source before relying on it.
