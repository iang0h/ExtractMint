Core conversion runs locally in your browser.

The original document is not sent to a conversion server. The optional assistant sends a limited extracted context only when you submit a question.

Current posture (static build)

  • Browser-side processing for document conversion.
  • The original document is not sent to a conversion server.
  • No account or sign-in is required.
  • Asking the assistant sends your question, file name, document details, and up to five extracted rows to the agent endpoint; a configured AI provider may receive them. The original PDF is not included.
  • Optional local caches (OCR + PDF review index) that can be cleared.

Accountant workflow checklist

  • Use a dedicated browser profile with minimal extensions.
  • Confirm the domain is extractmint.iangoh.com before processing client documents.
  • After export, validate opening/closing balances and review low-confidence rows.
  • Clear all local caches after completing a client batch if required.

What this is not

  • This page is not a compliance certification claim.
  • Like any browser app, device hygiene and extensions can affect security.
