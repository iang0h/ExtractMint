Privacy

What stays in your browser—and what you choose to send.

Core conversion runs in your browser. The optional assistant and site analytics use separate, limited data flows.

File conversion

  • Core PDF, image, and document conversion runs in your browser; the original file is not sent to a conversion server.
  • No account or sign-in is required.
  • Optional browser caches can speed repeat work and can be cleared in the app.

Ask ExtractMint

When you submit a question with a converted document active, the browser sends the question and a compact context to ExtractMint’s /api/agent/ endpoint. The context includes the file name, document type, currency, statement period, row count, confidence and validation details, plus up to five extracted rows with dates, descriptions, amounts, deposits, withdrawals, and balances. The original PDF is not included.

If an AI provider is configured for the assistant, the question and context are forwarded to that provider. Otherwise, the endpoint uses built-in guidance. Avoid asking about a document if you do not want these selected details sent to the endpoint and, when configured, the AI provider. Review the provider’s privacy terms for its handling and retention.

Website analytics

ExtractMint uses Vercel Web Analytics for page views and three fixed product events: upload_started, conversion_completed, and export_started. The synthetic example has four separate demo-only events: sample_conversion_started, sample_conversion_completed, sample_conversion_failed, and sample_conversion_cancelled when a real upload takes precedence. These demo-only events carry no properties. All seven events include no custom properties, so no filenames or statement contents are sent with them. Vercel describes Web Analytics as cookie-free and based on anonymized data.

Local OCR cache (optional)

For scanned PDFs, ExtractMint may OCR pages. You can persist an OCR cache locally so repeat exports are faster.

Local PDF review index (optional)

For review-mode matching, ExtractMint can cache per-page text indices locally in your browser.

Clear all caches

Use the in-app Trust & privacy panel and click “Clear all local caches” for accountant workflows.

Accountant workflow checklist

  • Use a dedicated browser profile for client work.
  • Verify opening and closing balances after export.
  • Clear caches after finishing a client batch if required by policy.
